# Drift-study notebook companions

- [drift_pilot.ipynb](drift_pilot.ipynb): bounded-drift study companion.
- [direct_drift_pilot.ipynb](direct_drift_pilot.ipynb): direct pooled-rule comparison.

Install the root [requirements.txt](../../requirements.txt) and select that
Python environment as the notebook kernel. Run commands from the repository
root, or follow each notebook's explicit root discovery.

These notebooks contain saved synthetic results and plots, not private input
photos or a hardware experiment. Their setup references have been updated;
saved numerical outputs are retained. The source-controlled JSON summaries and
compressed replay files remain the authoritative inputs for the
[replay verifier](../scripts/README.md).

A cleanup/schema check is not a fresh scientific rerun. To regenerate outputs,
use a clean kernel and follow the frozen protocol and full builder workflow.
Do not treat an old saved output as validation of changed code or assumptions.
Historical exploratory notebook archives stay local and are not maintained
entry points.
